# memc.farm

Static site for **MEMC Wild Roots Farmhouse & Restaurant** — Manahara Chowk, Ratnanagar-08, Chitwan, Nepal.

Served by GitHub Pages at <https://memc.farm>. No build step, no dependencies: HTML, CSS, one JS file and images.

Deploy: push to `main`.
